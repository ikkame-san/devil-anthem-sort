# Devil ANTHEM.楽曲ソート

Devil ANTHEM. の好きな曲を選び、自分だけのランキングを作る非公式ファンサイト。
HTML / CSS / JavaScript の静的サイトで、GitHub Pages のプロジェクト配下に公開できます。外部パッケージのインストールは不要です。

## 使い方

1. ランキング対象の曲を選び、何位まで作るか決める。ボタンで上位15曲・上位25曲・全曲を選べ、数値も直接入力できる。
2. 2曲は左右に並べて好きなほうを1回タップする。3曲は横3列、4曲は2×2に並べ、好きな順にタップして番号を確認して確定する。
3. ランキングが完成したら、ジャケット写真入りの PNG 画像を保存する。上位3曲は金・銀・銅の装飾付きで大きく表示し、4位以降は左列の上から下、右列の上から下へ順位が続く2列に配置する。対応ブラウザでは画像を共有でき、結果リンクやテキストのコピー、Xへの共有も可能。

曲は同順位を設けず、好きな順を選ぶ方式です。選んだ曲をもう一度タップすると選択を取り消せます。ブラウザの localStorage に自動保存し、30回分の選択を戻せます。タップ中の順位は確定するまで保存されません。

## ローカルで起動

Node.js 20 以上で、作業フォルダから次を実行します。

```sh
node scripts/build-jackets.mjs
npm start
```

[http://127.0.0.1:4173](http://127.0.0.1:4173) を開きます。ES Modulesを使用しているため、HTMLの直接ダブルクリックではなくHTTPサーバーで起動してください。

```sh
npm run check
npm test
```

テストはランダムなピボットと多数の曲数・ランキング長、5曲の全順列、途中保存からの復帰、ブロック省略、入力検証、楽曲データを確認します。

## GitHub Pages で公開

公開リポジトリ `ikkame-san/devil-anthem-sort` を作成し、ソースを `main` ブランチへ push します。

リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に変更してください。必要なら **Actions → Deploy to GitHub Pages → Run workflow** を実行します。

公開URL: `https://ikkame-san.github.io/devil-anthem-sort/`

ワークフローは構文チェック・テスト後、公開用の6ファイルと公式ジャケット画像をPagesへ配信します。以降は `main` へのpushで自動更新されます。画像の取得に失敗した場合は公開を中止し、前の公開版を維持します。

## 楽曲リスト

2026-10-06 に[公式ディスコグラフィー](https://devilanthem.net/#/discography/)の49作品を確認し、93項目を収録しています。

- 別年度の再録音源は同じ曲としてまとめています。
- インストゥルメンタル版は除外し、オリジナルのイントロ曲とリミックスは個別に掲載しています。
- 「①②③④⑤」と「①②③④⑤⑥」は公式の別タイトルとして個別に掲載しています。
- 発売予定の4曲は既定で非表示です。「発売予定の曲も表示する」で選択できます。表示判定には日本時間の今日の日付を使用します。
- 公式表記のUnicode結合文字、波ダッシュ、空白、年度バージョン表記を整理しています。
- 「Ride on 魅太陽」の年は、ディスコグラフィーの誤記を[公式リリース告知](https://devilanthem.net/news/public/_/qg3oifnbvixxnqky.html)に基づき2026へ訂正しています。

`songs.js` には各曲の参照URLを保持しています。追加曲はUIから入力できます。公開カタログの更新は `songs.js` を編集してください。IDは曲名から生成した固定値なので、既存IDを維持してください。

93曲に公式リリースのジャケット画像を設定し、曲一覧・比較・順位付け・結果画面に表示します。画面の画像は公式サイトのURLを参照し、取得できない場合は音符の表示に戻ります。保存・共有するPNG画像にも、曲名と順位の横にジャケット写真を入れます。PNGには公開時に取得した同一オリジンの画像を使用し、ブラウザのCanvas制限を回避します。ジャケット未登録の追加曲は音符を表示します。

公式YouTubeチャンネルの[MV](https://www.youtube.com/playlist?list=PLFWX8yVCqaWz-8orvrNZso1J8vRw7kasO)、[公式音源](https://www.youtube.com/playlist?list=PLFWX8yVCqaWyErIlgVlLZnRyy-L_m1ogF)、[ダンス動画](https://www.youtube.com/playlist?list=PLFWX8yVCqaWyltjsD_KvUTib-zErW2GQM)、[ライブ映像](https://www.youtube.com/playlist?list=PLFWX8yVCqaWz8VvyElg7WvjITQjaV6ECT)から72曲の動画を確認しています。MVを優先し、動画ボタンを押したときだけプレーヤーを読み込みます。閉じると再生を停止します。動画未確認の曲・追加曲には「YouTubeで検索」を表示し、曲名と「Devil ANTHEM.」を組み合わせた検索結果を別タブで開きます。曲一覧・順位付け・比較・共有結果の各画面で使えます。

`scripts/catalog-research.mjs` と `scripts/build-catalog.mjs` は公式公開曲目を確認・整理する保守用ツールです。`scripts/build-media.mjs` は公式プレイリストとリリースページからジャケット・動画を対応付けます。研究用の一時ファイルはGitと公開対象から除外しています。ページ構造が変わった場合は、生成データを公式情報と照合してください。

## 保存・共有

選択・途中結果・名前は端末のブラウザ内に保存されます。サーバーやデータベースへの送信はありません。共有リンクのURLフラグメントには曲名・順位・任意の名前・作成日・対象曲数が含まれ、リンクを受け取った人が表示できます。曲名を格納しているので、後日カタログが更新されても共有結果は変わりません。

Web Share APIが画像に対応しない環境では、結果リンクのコピーを案内します。PNG画像はスマホ・PCとも保存可能で、長い曲名は折り返します。多数の曲をランキングにすると画像が縦長になります。端末のフォントを使用します。ジャケット表示時は公式画像ホスト、動画を開いたときはYouTubeへ接続します。
